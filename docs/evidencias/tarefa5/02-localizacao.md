# Localizacao dos volumes

- Banco: achadosperdidos_dados_banco -> /var/lib/docker/volumes/achadosperdidos_dados_banco/_data -> /var/lib/postgresql/data
- Fotos: achadosperdidos_fotos -> /var/lib/docker/volumes/achadosperdidos_fotos/_data -> /app/uploads

No Docker Desktop, os Mountpoints pertencem ao ambiente Linux do Docker, e nao a uma pasta comum do projeto no Windows.
